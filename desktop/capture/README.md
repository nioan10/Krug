# Изолированный захват звука Windows

Внутренний компонент для будущего настольного клиента. Сам по себе он не является приложением Круг и ещё не подключён к звонкам.

Сборка: `dotnet build desktop/capture/Krug.Capture.csproj -c Release`. Требуются .NET SDK 9 и Windows 10 build 20348 или новее. Зависимость NAudio использует WASAPI process loopback в режиме включения дерева выбранного процесса; захват всего системного звука здесь не предусмотрен.

Родительский процесс запускает компонент с единственным аргументом — PID, выбранным пользователем. На stderr приходит строка `READY 44100 2 f32le` после запуска; stdout содержит только PCM float32 little-endian, 44 100 Гц, два чередующихся канала. Строка или закрытие stdin завершает захват; завершение выбранного процесса тоже завершает его. Если потребитель не успевает за потоком, старые пакеты отбрасываются, чтобы не накапливать задержку. Старт может завершиться ошибкой; клиент обязан явно сообщить об этом и не переходить на системный звук.

Захват реального звука и изоляция от остальных процессов ещё не проверены. Перед выпуском необходим тест с двумя независимыми синтетическими источниками и проверка закрытия выбранного процесса, завершения звонка и отмены пользователем.
