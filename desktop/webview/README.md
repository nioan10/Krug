# Изолированный прототип WebView2

Это исследовательский прототип, не замена установленного клиента. Он открывает только тестовый локальный адрес `http://127.0.0.1:9350`, не подключается к действующему серверу и не предоставляет веб-странице доступ к нативным функциям. `bridge.js` — заготовка протокола, пока не подключённая к приложению.

Для сборки нужны .NET SDK, .NET Framework 4.8 и доступ к NuGet: `dotnet build desktop/webview/Krug.Webview.csproj -c Release`. На Windows 11 системный WebView2 Runtime обычно уже установлен; на некоторых Windows 10 его понадобится установить отдельно. Прототип на этой машине загрузил тестовый интерфейс в системном WebView2; в отдельном тесте проверена передача синтетических PCM-данных в JavaScript без воспроизведения.

Для полноценной замены ещё необходимы: безопасная нативная связка выбора приложения и WASAPI с жизненным циклом звонка; перенос сессии из Electron; собственное безопасное автообновление; совместимый установщик, удаляющий старый движок при обновлении; проверка звука и видеодемонстрации через LiveKit. Не выпускать прототип как рабочий клиент до этих проверок.
