# Windows-клиент (разработка)

Этот клиент пока находится в разработке: установщик собирается, но сквозная проверка демонстрации с LiveKit и развёртывание обновлённого интерфейса ещё не завершены. Не распространяйте его как готовый выпуск.

Нужны Node.js 24+, pnpm 11.25.0 и .NET SDK 9. Установите зависимости `pnpm install --frozen-lockfile`, затем выполните `pnpm desktop:build`. Установщик появится в `release/`. Он не подписан. Клиент открывает существующий сервер Круга и хранит свою сессию отдельно от браузера. После сборки клиенту нужен сервер с совместимой версией интерфейса.

Звук выбранного окна доступен на Windows 10 build 20348 и новее. Захватывается дерево процесса, которому принадлежит окно; у приложений с отдельными уже запущенными процессами звук может не попасть в дерево. Если источник недоступен, системный звук автоматически не подставляется. Обновляйте установку после выхода из звонка. Автоматическое обновление самого установщика пока не реализовано; обновления интерфейса обрабатываются существующей системой приложения.
