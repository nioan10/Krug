# Windows-клиент (разработка)

Этот клиент пока находится в разработке: установщик собирается, но сквозная проверка демонстрации с LiveKit и развёртывание обновлённого интерфейса ещё не завершены. Не распространяйте его как готовый выпуск.

Нужны Node.js 24+, pnpm 11.25.0 и .NET SDK 9. Установите зависимости `pnpm install --frozen-lockfile`, затем выполните `pnpm desktop:build`. Установщик появится в `release/`. Он не подписан. Клиент открывает существующий сервер Круга и хранит свою сессию отдельно от браузера. После сборки клиенту нужен сервер с совместимой версией интерфейса.

Звук выбранного окна доступен на Windows 10 build 20348 и новее. Захватывается дерево процесса, которому принадлежит окно; у приложений с отдельными уже запущенными процессами звук может не попасть в дерево. Если источник недоступен, системный звук автоматически не подставляется.

Приложение автоматически проверяет сервер после открытия и затем каждые 10 минут. После входа в аккаунт новая версия загружается в фоне и устанавливается автоматически, когда звонок не активен; после выхода из звонка приложение перезапускается. Обновление интерфейса обрабатывается отдельно существующим механизмом PWA. Сборка не подписана сертификатом издателя: HTTPS и проверка хеша загрузки защищают передачу, но не заменяют цифровую подпись.

## Проверка звука с другом

Войдите в одну голосовую комнату с другого устройства. На компьютере откройте два независимых приложения с разными звуками, выберите окно первого в диалоге демонстрации и отметьте передачу звука. Второй участник должен слышать только выбранный процесс и его дочерние процессы. Остановите первое приложение и убедитесь, что передача прекратилась; повторите проверку с другим окном и при отмене выбора. Разные вкладки одного браузера могут принадлежать одному дереву процессов и потому передаваться вместе. Если приложение выводит звук через отдельный процесс вне выбранного дерева, звук может отсутствовать.

## Публикация следующей версии

Повысьте `version` в `package.json`, обновите lock-файл и соберите установщик. В `release/` появятся `latest.yml` и `Krug-Setup-<версия>.exe`. На сервере скопируйте EXE во внешний каталог `desktop-updates`, затем атомарно замените в том же каталоге `latest.yml`. Порядок важен: клиент должен видеть новый манифест только после полной загрузки установщика. Каталог монтируется в контейнер приложения только для чтения; он не входит в Git. Доступ к файлам требует короткоживущий токен, который выдаётся только вошедшему участнику и не даёт доступа к переписке или настройкам.
